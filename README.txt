State Life Calculator — updated design & PDF sharing.
Open index.html in Chrome/Edge. The PDF download/share library is loaded from cdnjs and requires internet on first load. Print works without it. Share uses the native share menu on supported HTTPS/mobile browsers, otherwise downloads the PDF.
Rates are user-supplied, NOT verified official State Life figures. Maturity 5x is shown only for 03/20 as requested and is illustrative. Death benefits are formulas with bonus pending. No profession field. Browser print headers/footers must be disabled in print dialog.
